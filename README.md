## 📊 Краткий обзор проекта

**Project Skebob** — это Android-клиент для работы с API фактов, построенный на принципах чистой архитектуры.

*   **Архитектура:** MVVM (Model-View-ViewModel)
*   **Хранение:** SQLite (Offline-first approach)
*   **Связь:** Retrofit 2 + Coroutines
*   **Дизайн:** Adaptive Material Design (Portrait/Landscape)
