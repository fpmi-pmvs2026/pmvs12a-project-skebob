## 2. Описание компонентов

### 📂 java/com/example/project_skebob/
Это основной пакет приложения, содержащий логику и UI-компоненты.

*   **MainActivity.kt** — Главный контейнер приложения. Управляет навигацией (`BottomNavigationView`) и сменой фрагментов.
*   **ListFragment.kt** — Фрагмент для отображения общего списка фактов и взаимодействия с API.
*   **FavoritesFragment.kt** — Фрагмент, отображающий только те записи, которые были отмечены как избранные.
*   **MainViewModel.kt** — "Мозг" приложения. Хранит данные в `LiveData`, обрабатывает асинхронные запросы (Coroutines) и взаимодействует с БД.
*   **FactsAdapter.kt** — Связующее звено между данными и списком `RecyclerView`. Обрабатывает клики и свайпы.
*   **DatabaseHelper.kt** — Логика работы с SQLite: создание таблиц, SQL-запросы для агрегации и фильтрации.
*   **ApiClient.kt** — Настройка библиотеки Retrofit для сетевых запросов.
*   **DataModel.kt** — Описание структур данных (`FactRecord`, `ApiFactResponse`).

### 📂 res/layout/ & res/layout-land/
*   **activity_main.xml** — Верстка главного экрана с контейнером для фрагментов.
*   **fragment_list.xml** — Верстка списков. В папке `layout-land` находится оптимизированная версия для горизонтальной ориентации.

---

## 3. Вспомогательные файлы
*   **AndroidManifest.xml** — Регистрация Activity и запрос разрешений на интернет.
*   **themes.xml** — Стили приложения (настроено скрытие ActionBar).
*   **bottom_nav_menu.xml** — Конфигурация пунктов нижнего меню.

> [!TIP]
> При добавлении новых функций всегда разделяйте описание данных в `DataModel.kt` и логику их обработки в `MainViewModel.kt`.
