# 📚 Project Skebob

Добро пожаловать в Wiki проекта **Project Skebob**! Это центральный узел документации, где собраны технические подробности реализации, описание архитектуры и инструкции по развитию приложения.

---

## 📝 Описание задачи

**Project Skebob** — это учебный проект по разработке Android-приложения на языке Kotlin, целью которого является создание удобного клиента для работы с API фактов. Приложение служит демонстрацией владения современным стеком Android-разработки и паттернами проектирования.

**Основные цели проекта:**
*   Реализация сетевого взаимодействия с использованием **Retrofit**.
*   Организация локального хранения данных в **SQLite** с поддержкой агрегационных функций.
*   Построение архитектуры на базе **MVVM (Model-View-ViewModel)**.
*   Создание адаптивного интерфейса, корректно работающего в разных ориентациях экрана.

## 🛠 Технологический стек

Проект использует следующие инструменты и библиотеки:
*   **Language:** Kotlin
*   **UI:** XML (Material Design), Activity & Fragments
*   **Database:** SQLite (SQLiteOpenHelper)
*   **Networking:** Retrofit 2 + Gson
*   **Asynchrony:** Kotlin Coroutines
*   **Lifecycle:** ViewModel, LiveData
